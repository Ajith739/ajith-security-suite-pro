# Gracewell Security Suite Pro — sales packaging

**Positioning:** WordPress security operations for site owners and small teams who want understandable controls, verifiable account protection and a clear investigation workflow.

**Short copy:** Protect WordPress accounts, investigate suspicious files and manage security events from one clear workspace. Gracewell Security Suite Pro combines passkeys, two-factor recovery, login protection, a query firewall and scheduled integrity scans.

**Long copy:** Stay in control of everyday WordPress security. Manage trusted visitors and reverse proxies, restrict abusive IPs, enroll passkeys and recovery methods, schedule file inspection and review source changes before taking action. A responsive dashboard connects retained events with audit logs, local file findings and actionable administration. Local verification and bounded background work keep external dependencies optional and visible.

## Feature summary
- Passkey enrollment, naming, revocation and passwordless sign-in.
- TOTP, one-use recovery codes and verified email/SMS backups.
- Login rate limiting, escalation, custom routes and per-role rules.
- IPv4/IPv6 restrictions with reasons, expiry and audit history.
- Opt-in query firewall and explicit trusted-proxy boundaries.
- Scheduled integrity inspection, coverage reporting, source review and quarantine.
- Cached attribution of site denials, local-time logs and accessible notifications.
- Module settings and portable configuration with secrets excluded.

## Sales boundaries
Describe local suspicious-file and integrity inspection, not guaranteed malware eradication. Explain WP-Cron traffic dependence, HTTPS for passkeys, delivery setup, provider costs and server-specific hardening. Country blocking, remote global intelligence subscriptions, license/renewal billing and guaranteed priority support are not implemented claims. The seller must finalize sales-channel licensing, support terms, refunds and illustration redistribution rights.
