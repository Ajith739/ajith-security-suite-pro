# Data handling and compliance scope

This is an engineering data-flow description, not GDPR/SOC 2 certification or legal advice. Audit logs, IPs, usernames, authentication material and quarantine evidence are sensitive site data. Retain the site's configured privacy/retention controls and existing key material. Reports are administrator-only, nonce protected, no-cache downloads; HTML is escaped and uses no external scripts. Legacy descriptions reuse credential redaction. Exported files leave WordPress access controls and require private storage.

Optional existing external integrations include WordPress.org integrity/repair requests, AbuseIPDB visitor-IP lookups, and configured alert/collector destinations. A service must be explicitly configured and its existing disclosure/opt-in reviewed. This upgrade adds no telemetry or automated account outreach. There is no commercial certification evidence, commissioned auditor, DPA or deployment approval in this repository.
